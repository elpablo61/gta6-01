Crescent Bay — a sun-soaked open-world crime game. You are Rook, a driver new in town: steal any car, outrun the police across a living city of traffic and pedestrians, and run eight jobs for fixer Mara Voss and wheelman Dante Cole — from a first pickup to a dockside heist. Wanted level 1–5 stars with foot cops, patrol cars and roadblocks, day/night cycle, combat, and a save game. Built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows to move and drive, mouse to aim, click to shoot, E to enter/exit a car, Shift to sprint, Space for the handbrake, Esc/P to pause.
